# Тренажёр ЭкТ — спецификация

Сайт для подготовки к тестам по «Экономической теории» (БГУИР, гр. 673901) по конспекту
`source/konspekt.html`. Движок взят из тренажёра английских слов (`app-template.html` + `build.py`
→ один самодостаточный `index.html`, без сервера, прогресс в `localStorage`, перенос файлом).

## Структура

| Путь | Что |
|---|---|
| `source/konspekt.html` | Конспект (источник истины). Не редактировать |
| `source/formulas.html` | Расшифровка формул |
| `source/кругооборот.svg/png` | Схема кругооборота |
| `data/topic-NN.json` | Данные тренажёра по темам (формат ниже) |
| `app-template.html` | Шаблон приложения, маркер `/*__TOPICS__*/[]` |
| `build.py` | Собирает `index.html` из шаблона и `data/topic-*.json`, копирует конспект в `konspekt.html` |
| `index.html`, `konspekt.html` | Результат сборки (коммитится, его отдаёт GitHub Pages) |

## Формат `data/topic-NN.json`

Все поля, кроме `n`, `title`, `section`, необязательны; пустые массивы можно опускать.
Тексты — только из конспекта, дословно или близко к нему. Ничего не выдумывать.

```json
{
  "n": 1,
  "title": "I.1 Потребности и производство",
  "section": "Лекции",
  "cards":    [["термин", "определение", "тег"]],
  "authors":  [["автор", "труд или идея", "школа"]],
  "lists":    [{"q": "Назовите все функции экономической теории", "items": ["...", "..."]}],
  "chrono":   [["событие или школа", "период/год", 1776]],
  "pairs":    [["понятие A", "понятие B", "чем отличаются"]],
  "formulas": [["название", "формула", "что означают обозначения"]],
  "questions":[["вопрос самопроверки", "ответ"]]
}
```

- `section` — одно из: `Лекции`, `Эволюция мысли`, `Шпаргалки`.
- `chrono[i][2]` — число для сортировки (год начала периода).
- `n` — уникальный номер; диапазоны: лекции 1–19, эволюция мысли 20–39, шпаргалки 40–59.

## Режимы (вариант B)

Из движка: **Темы** (список с прогрессом), **Карточки**, **Заучивание** (1 из 4), **Письмо**,
**Подбор** (пары на время), **Тест**, **Список** — все работают по `cards`.

Новые режимы ЭкТ:
- **Кто что написал** — автор ↔ труд/идея, выбор 1 из 4 в обе стороны (`authors`).
- **Назови все** — по вопросу ввести/отметить все элементы списка, показ пропущенных (`lists`).
- **Хронология** — расставить 5–7 случайных пунктов по порядку перетаскиванием (`chrono`).
- **Путаница** — показывается описание отличия, выбрать, к какому из пары относится (`pairs`).
- **Формулы** — карточки «название → формула + расшифровка» (`formulas`).
- **Самопроверка** — вопрос → показать ответ → «знал / не знал» (`questions`).
- **Конспект** — вкладка/ссылка на `konspekt.html` (копия `source/konspekt.html`).

Режим показывается для темы, только если у неё есть соответствующие данные.
Можно выбрать «Все темы раздела» для любого режима.
