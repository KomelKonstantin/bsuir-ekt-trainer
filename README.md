# Тренажёр ЭкТ — БГУИР

Статический сайт-тренажёр по «Экономической теории» (БГУИР) по конспекту лекций
`source/konspekt.html`. Один самодостаточный `index.html`: без сервера, без внешних
библиотек и шрифтов, прогресс хранится в `localStorage` браузера (ключ `ekt-trainer-progress-v1`)
и переносится между устройствами файлом. Публикуется через GitHub Pages из корня ветки `main`.

Контракт данных и список режимов — в [`SPEC.md`](SPEC.md), он главный.

## Режимы

Главный экран **Темы** — темы, сгруппированные по разделам (Лекции, Эволюция мысли, Шпаргалки),
с прогрессом и пунктом **«Все темы раздела»**. Любой режим работает и по одной теме, и по разделу
целиком. Вкладка режима показывается, только если в выбранных темах есть нужные данные.

| Режим | Данные | Что делать |
|---|---|---|
| Карточки | `cards` | Термин ↔ определение, «Знаю / Ещё учить», ★ трудное |
| Заучивание | `cards` | Выбор 1 из 4 (направление переключается) |
| Письмо | `cards` | По определению ввести термин; регистр, ё/е и лишние пробелы не важны, пояснение в скобках можно опустить |
| Подбор | `cards` | Соединить 6 пар «термин — определение» на время |
| Тест | `cards` | 10 / 20 / все вопросы, выбор или написание, разбор ошибок в конце |
| Список | `cards` | Таблица с поиском и отметкой ★ |
| Кто что написал | `authors` | Автор → труд/идея и труд → автор, 1 из 4, после ответа — школа |
| Назови все | `lists` | Вводить пункты по одному; затем «Показать все» — пропущенные подсвечиваются, их можно отметить как известные |
| Хронология | `chrono` | Расставить 5–7 случайных пунктов по порядку: перетаскиванием или кнопками ↑ ↓ |
| Путаница | `pairs` | Дано описание отличия (названия понятий скрыты ▢) — выбрать, о какой паре речь; затем показывается полное объяснение |
| Формулы | `formulas` | Карточки «название → формула + расшифровка» |
| Самопроверка | `questions` | Вопрос → «Показать ответ» → «Знал / Не знал» |
| Конспект ↗, Формулы ↗ | — | Ссылки на `konspekt.html` и `formulas.html` |

Фильтр «Все / Невыученные / Трудные ★» работает во всех режимах, кроме Хронологии.
Окно «Прогресс · файл» сохраняет прогресс в JSON-файл и загружает его (объединяя с текущим).

## Сборка

```bash
python3 build.py            # из data/topic-*.json
python3 build.py --sample   # из тестовых data/_sample/topic-98.json и topic-99.json
```

`build.py` (только стандартная библиотека Python 3):

- читает `data/topic-*.json`, проверяет обязательные поля (`n`, `title`, `section`), типы и длины
  кортежей, уникальность `n`, и печатает все ошибки сразу с именем файла и индексом записи;
- вставляет темы в `app-template.html` вместо маркера `/*__TOPICS__*/[]` и пишет `index.html`;
- копирует `source/konspekt.html` → `konspekt.html` и `source/formulas.html` → `formulas.html`.

Добавить тему: положить `data/topic-NN.json` по формату из `SPEC.md` и пересобрать.
Результат сборки (`index.html`, `konspekt.html`, `formulas.html`) коммитится.

Прогресс хранится по номеру темы и тексту записи (термину, вопросу, автору…), поэтому
перестановка записей в JSON его не сбрасывает, а исправление текста термина — сбрасывает только эту запись.
